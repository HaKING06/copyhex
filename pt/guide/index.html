CopyHex

Como usar

CopyHex é um espaço gratuito para designers, desenvolvedores e quem cria com cores.

01

Cores

Dica: pesquise “vermelho”, “azul” ou cole HEX, RGB ou HSL. Nomes em inglês também funcionam.

02

Descobrir paletas

Encontre uma combinação, ajuste os tons e salve sua versão.

03

Gerador de paletas

Escolha cor, harmonia e estilo. Bloqueie seus tons, gere opções e confira o contraste.

04

Estúdio de cores

Ajuste a cor, copie o código e salve seu tom.

05

Verificar contraste

WCAG AA exige 4,5:1 para texto normal e AAA, 7:1. Para texto grande, AA exige 3:1. Verifique pares reais e não comunique só pela cor.

06

Paleta a partir de imagem

Escolha PNG, JPEG ou WebP. A imagem fica no seu dispositivo.

07

Exportar paleta

CSS para código, JSON para dados, SVG para gráficos editáveis e PNG para revisão. Exporte o backup completo separadamente em Minhas paletas.

08

Exportar backup

Paletas, favoritos e preferências ficam neste navegador, sem sincronização entre dispositivos. Exporte um backup antes de limpar os dados. Imagens são processadas no dispositivo.
