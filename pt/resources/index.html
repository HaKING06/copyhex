Guias de cores

Encontre códigos de cores HEX, RGB e HSL. Crie paletas harmoniosas, salve tons e baixe combinações com CopyHex.

Harmonias: como combinar cores ↗

Cores análogas são vizinhas, complementares são opostas e tríades usam três famílias. Mantenha uma base e varie luminosidade e saturação. Harmonia não garante legibilidade.

Paleta de marca a partir de uma cor ↗

Escolha cor, harmonia e estilo. Bloqueie seus tons, gere opções e confira o contraste.

Paletas acessíveis e contraste ↗

WCAG AA exige 4,5:1 para texto normal e AAA, 7:1. Para texto grande, AA exige 3:1. Verifique pares reais e não comunique só pela cor.

Extrair uma paleta de imagem ↗

Escolha PNG, JPEG ou WebP. A imagem fica no seu dispositivo.

Exportar paletas: CSS, SVG, PNG e JSON ↗

CSS para código, JSON para dados, SVG para gráficos editáveis e PNG para revisão. Exporte o backup completo separadamente em Minhas paletas.
