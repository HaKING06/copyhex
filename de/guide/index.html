CopyHex

Anleitung

CopyHex ist ein kostenloser Arbeitsbereich für Design, Entwicklung und kreative Farbideen.

01

Farben

Tipp: Suche „rot“, „blau“ oder füge HEX, RGB oder HSL ein. Englische Farbnamen funktionieren ebenfalls.

02

Paletten entdecken

Finde eine Kombination, passe Farbtöne an und speichere deine Version.

03

Palettengenerator

Wähle Ausgangsfarbe, Harmonie und Stimmung. Sperre bevorzugte Farben, erzeuge Varianten und prüfe den Kontrast.

04

Farbstudio

Farbe anpassen, Code kopieren und Farbton speichern.

05

Kontrastprüfung

WCAG AA verlangt 4,5:1 für normalen Text, AAA 7:1. Für großen Text gilt bei AA 3:1. Prüfe reale Kombinationen und vermittle Bedeutung nicht allein durch Farbe.

06

Palette aus einem Bild

PNG, JPEG oder WebP wählen. Das Bild bleibt auf deinem Gerät.

07

Palette exportieren

CSS für Code, JSON für Daten, SVG für bearbeitbare Grafiken und PNG für Designabstimmungen. Exportiere die vollständige Sicherung separat unter Meine Paletten.

08

Sicherung exportieren

Paletten, Favoriten und Einstellungen bleiben in diesem Browser, ohne Gerätesynchronisierung. Exportiere vor dem Löschen eine Sicherung. Bilder werden auf deinem Gerät verarbeitet.
