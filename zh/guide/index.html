CopyHex

使用指南

CopyHex 是面向设计师、开发者和色彩创作者的免费工作区。

01

颜色

提示：搜索“红色”“蓝色”或粘贴 HEX、RGB、HSL。也支持英文颜色名称。

02

探索配色

寻找配色组合，调整色调，保存自己的版本。

03

配色生成器

选择起始色、配色规则和风格。锁定喜欢的颜色，生成方案并检查对比度。

04

色彩工作室

调整颜色，复制代码，保存专属色彩。

05

对比度检查

普通文字 WCAG AA 要求 4.5:1，AAA 为 7:1；大字 AA 为 3:1。请检查实际组合，且勿仅凭颜色传达信息。

06

从图片提取配色

选择 PNG、JPEG 或 WebP。图片仅在您的设备上处理。

07

导出调色板

CSS 用于开发，JSON 用于数据，SVG 用于可编辑图形，PNG 用于设计交流。完整收藏备份请在“我的调色板”中单独导出。

08

导出备份

调色板、收藏和设置仅保存在此浏览器，不会跨设备同步。清除数据前请导出备份。图片仅在本机处理。
