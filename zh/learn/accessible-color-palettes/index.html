CopyHex / 实用指南

无障碍配色与对比度

普通文字 WCAG AA 要求 4.5:1，AAA 为 7:1；大字 AA 为 3:1。请检查实际组合，且勿仅凭颜色传达信息。

如何使用这些颜色

选择背景、文字和强调色，使用前检查各组合的对比度。

导出调色板

CSS 用于开发，JSON 用于数据，SVG 用于可编辑图形，PNG 用于设计交流。完整收藏备份请在“我的调色板”中单独导出。
