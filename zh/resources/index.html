CopyHex / 色彩指南

色彩指南

使用 CopyHex 查找 HEX、RGB 和 HSL 颜色代码，创建和谐配色、收藏色彩并下载调色板。

色彩和谐：如何搭配颜色 ↗

邻近色彼此相邻，互补色位于对面，三角色使用三个色系。保留基准色并调整明度和饱和度。配色和谐不代表文字一定清晰。

从一种颜色创建品牌配色 ↗

选择起始色、配色规则和风格。锁定喜欢的颜色，生成方案并检查对比度。

无障碍配色与对比度 ↗

普通文字 WCAG AA 要求 4.5:1，AAA 为 7:1；大字 AA 为 3:1。请检查实际组合，且勿仅凭颜色传达信息。

从图片提取调色板 ↗

选择 PNG、JPEG 或 WebP。图片仅在您的设备上处理。

导出配色：CSS、SVG、PNG 和 JSON ↗

CSS 用于开发，JSON 用于数据，SVG 用于可编辑图形，PNG 用于设计交流。完整收藏备份请在“我的调色板”中单独导出。
