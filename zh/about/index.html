色彩工作区

使用 CopyHex 查找 HEX、RGB 和 HSL 颜色代码，创建和谐配色、收藏色彩并下载调色板。

配色生成器

选择起始色、配色规则和风格。锁定喜欢的颜色，生成方案并检查对比度。

隐私与数据

调色板、收藏和设置仅保存在此浏览器，不会跨设备同步。清除数据前请导出备份。图片仅在本机处理。

系列

6,000 种唯一 HEX 颜色。数据来自 David Aerne 及贡献者的 Color Names，采用 MIT 许可。社区名称并不都属于 CSS 关键字。
