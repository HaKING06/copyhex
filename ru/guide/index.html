CopyHex

Как пользоваться

CopyHex — бесплатное пространство для дизайнеров, разработчиков и всех, кто работает с цветом.

01

Цвета

Совет: ищите «красный», «синий» или вставьте HEX, RGB либо HSL. Английские названия тоже работают.

02

Подборки палитр

Найдите сочетание, измените оттенки и сохраните свою версию.

03

Генератор палитр

Выберите начальный цвет, гармонию и настроение. Закрепите любимые оттенки, создайте варианты и проверьте контраст.

04

Студия цвета

Настройте цвет, скопируйте код и сохраните нужный оттенок.

05

Проверка контраста

Для обычного текста WCAG AA требует 4,5:1, AAA — 7:1. Для крупного текста AA — 3:1. Проверяйте реальные пары и не передавайте смысл только цветом.

06

Палитра из изображения

Выберите PNG, JPEG или WebP. Изображение обрабатывается только на вашем устройстве.

07

Экспорт палитры

CSS подходит для кода, JSON — для данных, SVG — для редактируемой графики, PNG — для обсуждения дизайна. Полную резервную копию коллекции экспортируйте отдельно в разделе «Мои палитры».

08

Экспорт резервной копии

Палитры, избранное и настройки хранятся только в этом браузере. Синхронизации между устройствами нет. Перед очисткой браузера экспортируйте резервную копию. Изображения обрабатываются на устройстве.
