# Changelog

## 1.0.1 — 2026-11-08

- Expanded the catalog to exactly 6,000 unique HEX values with attributed, reproducible source data.
- Added indexed bilingual search, combined filters, nearest-RGB sorting and pagination.
- Added persistent light/dark/system appearance with pre-render theme initialization.
- Promoted Color studio to the main navigation with live RGB/HSL controls and per-format copying.
- Added color harmonies, recent colors, direct favorite/palette saving and shareable color URLs.
- Added installable PWA metadata, app icons, offline caching and explicit app-update controls.
- Added crawlable About and Guide pages, sitemap, structured data and social sharing metadata.
- Added a branded poster, improved support access and standardized copyhex.haking.tr / copyhex@haking.tr.
- Added MIT license, upstream notices, contribution guidance and automated build/test CI.
- Preserved 1.0.0 local collections and JSON backup compatibility.

## 1.0.0 — 2026-11-08

- Initial bilingual color catalog, favorites, named project palettes, conversion and contrast tools.
