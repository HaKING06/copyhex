# Product and search research — 2026-11-08

Exa was used to review 18 search results across four workstreams: palette-generation workflows, color-harmony/accessibility tools, Google international/image search guidance, and W3C contrast thresholds. Primary sources below informed implementation. Competitor workflows were used as requirements research; CopyHex layouts and curated palettes were authored for this project.

## Additional product decisions

Local image extraction addresses the common need to turn a reference image into a working palette without uploading it. CSS, JSON, SVG and PNG exports serve implementation, structured data, editable artwork and visual handoff respectively. Curated collections are copied into the user's collection instead of being mutated globally.

The smart generator uses local color-harmony rules, randomized exploration and a score that favors separation from locked colors and useful lightness differences. It does not call a generative AI service, infer brand strategy or guarantee accessibility. Contrast must be checked in the final design.

## Verification

The Node suite checks locked-color invariants, single-column isolation, palette size/uniqueness, monochromatic behavior, transparent-pixel exclusion, exports, all generated internal links, language/canonical metadata and sitemap contents. Browser checks cover discovery filtering, customization, lock/regenerate, undo/redo, save, locale switching, PNG download, local image extraction and layouts at 320/390/768 pixels. Final production-worker and offline checks are recorded in the task completion report.
