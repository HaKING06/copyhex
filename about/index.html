What is CopyHex?

CopyHex helps you find color codes, copy HEX, RGB, HSL and CMYK values, and organize project palettes. It brings discovery, conversion and collection into one focused workspace.

New in version 1.0.1

  • 6,000 distinct HEX values, advanced filters and pagination.
  • Persistent light/dark themes, live RGB/HSL controls and color harmonies.
  • Installable app, offline tools and shareable color links.
  • Usage guide, source attribution and a refined accessible interface.
  • 24 editable curated palettes and a smart generator with locks, single-color regeneration and alternatives.
  • Local image color extraction, CSS/JSON/SVG/PNG export and dedicated English/Turkish resource pages.

Color data and attribution

The catalog combines the original CSS colors with a distributed selection from Color Names by David Aerne and contributors. Duplicate HEX values are merged; alternative names remain searchable. Community names are descriptive labels, not necessarily CSS keywords. Color Names ↗ · MIT license

Turkish color families and common color words are searchable in either interface language. Community color names retain their original names. The RGB workspace covers opaque 8-bit sRGB colors; display color management can affect their appearance.

Privacy and your data

Favorites, palettes, theme, language and recent colors stay in your browser storage on this device. There are no accounts, analytics scripts or advertising trackers. Your collection does not sync across devices. Clearing browser storage can remove it; export JSON backups regularly. System fonts avoid external font requests. The hosting provider may process connection requests under its own policies.
