Harmonies : comment associer les couleurs

Les couleurs analogues sont voisines, les complémentaires opposées, les triades utilisent trois familles. Gardez une base et variez luminosité et saturation. L’harmonie ne garantit pas la lisibilité.

Harmonies : comment associer les couleurs

Les couleurs analogues sont voisines, les complémentaires opposées, les triades utilisent trois familles. Gardez une base et variez luminosité et saturation. L’harmonie ne garantit pas la lisibilité.

Comment utiliser ces couleurs

Choisissez un fond, un texte et un accent. Vérifiez le contraste de chaque paire.

Exporter la palette

CSS sert au code, JSON aux données, SVG aux visuels modifiables et PNG aux revues. Exportez la sauvegarde complète depuis Mes palettes.
