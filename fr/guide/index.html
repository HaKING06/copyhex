CopyHex

Mode d’emploi

CopyHex est un espace gratuit pour les designers, développeurs et créateurs.

01

Couleurs

Astuce : cherchez «rouge», «bleu» ou collez un code HEX, RGB ou HSL. Les noms anglais fonctionnent aussi.

02

Découvrir les palettes

Trouvez une combinaison, ajustez ses nuances et gardez votre version.

03

Générateur de palettes

Choisissez couleur, harmonie et ambiance. Verrouillez vos nuances, générez des variantes et vérifiez le contraste.

04

Studio couleur

Ajustez la couleur, copiez le code et enregistrez votre nuance.

05

Vérifier le contraste

WCAG AA exige 4,5:1 pour le texte courant, AAA 7:1. Pour le grand texte, AA exige 3:1. Vérifiez les paires réelles et n’utilisez pas uniquement la couleur.

06

Palette à partir d’une image

Choisissez PNG, JPEG ou WebP. L’image reste sur votre appareil.

07

Exporter la palette

CSS sert au code, JSON aux données, SVG aux visuels modifiables et PNG aux revues. Exportez la sauvegarde complète depuis Mes palettes.

08

Exporter une sauvegarde

Les palettes, favoris et réglages restent dans ce navigateur, sans synchronisation. Exportez une sauvegarde avant d’effacer les données. Les images sont traitées sur votre appareil.
