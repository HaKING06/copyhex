CopyHex

Cómo usar

CopyHex es un espacio gratuito para diseñadores, desarrolladores y quienes crean con color.

01

Colores

Consejo: busca «rojo», «azul» o pega HEX, RGB o HSL. También puedes usar nombres en inglés.

02

Descubrir paletas

Encuentra una combinación, ajusta los tonos y guarda tu versión.

03

Generador de paletas

Elige color inicial, armonía y estilo. Bloquea tus tonos favoritos, genera opciones y revisa el contraste.

04

Estudio de color

Ajusta el color, copia el código y guarda tu tono.

05

Comprobar contraste

WCAG AA exige 4,5:1 para texto normal; AAA, 7:1. Para texto grande, AA exige 3:1. Comprueba pares reales y no comuniques solo con color.

06

Paleta desde una imagen

Elige PNG, JPEG o WebP. La imagen se procesa solo en tu dispositivo.

07

Exportar paleta

CSS sirve para implementar, JSON para datos, SVG para gráficos editables y PNG para revisar diseños. Exporta la copia completa por separado desde Mis paletas.

08

Exportar copia

Las paletas, favoritos y preferencias quedan en este navegador. No hay sincronización entre dispositivos. Exporta una copia antes de borrar los datos. Las imágenes se procesan en tu dispositivo.
