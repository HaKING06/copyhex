Recursos de color

Encuentra códigos de color HEX, RGB y HSL. Crea paletas armoniosas, guarda tonos y descarga combinaciones con CopyHex.

Armonías de color: cómo combinar colores ↗

Los colores análogos son vecinos; los complementarios, opuestos; las tríadas usan tres familias. Conserva un color base y varía luminosidad y saturación. La armonía no garantiza texto legible.

Una paleta de marca desde un color ↗

Elige color inicial, armonía y estilo. Bloquea tus tonos favoritos, genera opciones y revisa el contraste.

Paletas accesibles y contraste ↗

WCAG AA exige 4,5:1 para texto normal; AAA, 7:1. Para texto grande, AA exige 3:1. Comprueba pares reales y no comuniques solo con color.

Extraer una paleta de una imagen ↗

Elige PNG, JPEG o WebP. La imagen se procesa solo en tu dispositivo.

Exportar paletas: CSS, SVG, PNG y JSON ↗

CSS sirve para implementar, JSON para datos, SVG para gráficos editables y PNG para revisar diseños. Exporta la copia completa por separado desde Mis paletas.
